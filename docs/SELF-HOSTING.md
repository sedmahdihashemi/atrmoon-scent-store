# راهنمای میزبانی عطرمون روی هاست شخصی (خروج کامل از سرور لوبل)

این راهنما سایت را روی هاست خودت اجرا می‌کند تا دیگر هیچ ترافیکی از سرورهای لوبل رد نشود و فیلتر بودن آن‌ها روی سایت تو اثر نداشته باشد.

## پیش‌نیازها روی هاست

- Docker و Docker Compose
- دامنه `atrmoon.top` با رکورد **A** به آی‌پی هاست خودت (هم برای `@` و هم برای `www`)
- پورت‌های 80 و 443 باز باشند (Caddy خودش گواهی SSL رایگان می‌گیرد)

## قدم ۱ — تست دسترسی به بک‌اند از هاست (مهم!)

روی هاست خودت این را اجرا کن (آدرس را از فایل `.env` بردار):

```bash
curl -i "<مقدار SUPABASE_URL از فایل .env>/rest/v1/"
```

- اگر پاسخ JSON گرفتی (حتی خطای 401) → بک‌اند از هاست تو **قابل دسترس است**؛ برو قدم ۲.
- اگر 403 با پیام منطقه/تحریم گرفتی یا timeout شد → بک‌اند هم برای هاست تو بسته است. در این حالت پروکسی `/sb` کمکی نمی‌کند و باید یک سرور کوچک خارج از ایران به‌عنوان پروکسی بگذاری یا بک‌اند را کامل به هاست خودت منتقل کنیم (خروج دیتا از تنظیمات پیشرفته لوبل + میزبانی Supabase روی هاست خودت). به من بگو تا آن مسیر را هم آماده کنم.

## قدم ۲ — سینک و اجرا

```bash
git pull            # آخرین نسخه پروژه از گیت‌هاب
cp .env .env.keep   # بکاپ، اختیاری
docker compose up -d --build
```

لاگ‌ها:

```bash
docker compose logs -f app
docker compose logs -f caddy
```

اگر همه‌چیز درست باشد، ظرف یک دقیقه `https://atrmoon.top` با SSL بالا می‌آید.

## قدم ۳ — قطع اتصال دامنه از لوبل

1. در Lovable: **Project Settings → Domains** → دامنه `atrmoon.top` و `www.atrmoon.top` را حذف کن (یا حداقل رکوردهای DNS را دیگر به 185.158.133.1 اشاره نده).
2. در پنل دامنه‌ات، رکوردهای A را به آی‌پی هاست خودت تغییر بده.
3. تا ۷۲ ساعت ممکن است propagation طول بکشد.

## قدم ۴ — به‌روزرسانی وبهوک ربات بله

بعد از بالا آمدن سایت، وبهوک را به آدرس جدید بفرست:

```
https://tapi.bale.ai/bot<TOKEN>/setWebhook?url=https://atrmoon.top/api/public/bale/webhook
```

## متغیرهای محیطی

| متغیر | کجا | توضیح |
|---|---|---|
| `VITE_SUPABASE_URL` | موقع build | پیش‌فرض: `https://atrmoon.top/sb` (پروکسی Caddy) |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | موقع build | همان کلید داخل `.env` |
| `SUPABASE_URL` | runtime | همان بالا، برای server functionها |
| `SUPABASE_PUBLISHABLE_KEY` | runtime | همان کلید |

برای استفاده از آدرس دیگری برای بک‌اند (مثلاً پروکسی خارج):

```bash
SELF_HOST_SUPABASE_URL=https://api.example.com docker compose up -d --build
```

## محدودیت‌های نسخه self-host

- `SUPABASE_SERVICE_ROLE_KEY` در لوبل کلاد در دسترس نیست؛ بنابراین دو قابلیت روی نسخه self-host فعال نمی‌شوند: **اطلاع‌رسانی سفارش در ربات بله** و **صف ایمیل**. خودِ ربات (ورود، پیگیری، نظر) کار می‌کند چون فقط به وبهوک و دیتابیس نیاز دارد. اگر این دو قابلیت برایت حیاتی‌اند، بگو تا با روش امن جایگزین (کلید API اختصاصی یا انتقال بک‌اند) درستشان کنم.
- به‌روزرسانی سایت = `git pull && docker compose up -d --build`.
